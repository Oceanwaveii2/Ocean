## 1. The Combination Law

> **Archetype class × unique transcript = unique variation.**

A generic class plus a distinctive script is all uniqueness requires. Jillian is not "the dumb blonde" — she is *her mined transcripts riding the class*: the class provides predictable read-by-audience framing; the transcripts provide the behavior nobody else has. Two characters can share a registry class and never behave alike because their Layer-1 evidence differs. This is why the two layers stay separate (Role doc §10): the class routes and frames; the transcript differentiates.

Worked example: Rick Sanchez = **the Mad Scientist** (US, adult-animation register). The class predicts the framing (amoral science, superiority, drank-to-cope brilliance); the *transcripts* deliver the specific nihilism cadence, the burp-speech timing, the family entanglement — the variation no other mad scientist has.

### 3.5 Brazilian / Lusophone (BR, 1960s–2026)
- **Novela binary tradition:** heroine vs villainess (villana), rich patriarch, humble heroine — Greek-archetype-rooted moral binary shared across Latin American telenovelas ([academic analyses](https://www.reddit.com/r/asklatinamerica/comments/dcvd96/what_are_some_common_character_archetypes_in/)).
- **Ideal-type function:** novela characters encode idealized types of women/men in Brazilian society — the registry's era coordinates matter most here (1960s vs Globo 1990s vs streaming-era).
- **Modern evolution:** recent novelas break types (asexual/aromantic central characters, Black women in central roles) — registry entries get era *end-dates* or `superseded_in_era` markers rather than edits.

## 4. Multi-Language Policy

- Every registry entry carries labels in **EN · JA · ZH · PT · HI** where the class exists in that culture; where it doesn't, the cross-culture analogue map carries it instead (Role doc §10).
- Language tracks are **mined separately** (existing JP/EN `moment_key` policy — same window, separate tracks, comparison happens in Eclipse).
- **Slang/era registers are data:** valley-girl speak, rap-era lexicons, 茶里茶气 phrasing, novela-era Portuguese — each is a register layer on the class, mined and versioned by era. A dumb blonde (1985) and a dumb blonde (2024) differ *at the register layer* even at the same class.
- Registry IDs: `archetype:<culture>:<era-range>:<slug>` per Role doc §10.

## 5. The Self-Learning Registry (AI mining feature)

The registry can **learn new classes from ingested media** — as a bounded AI sub-service (canon §2: LLM proposes, graph disposes):

1. **Unmatched-cluster detection:** mining ingests fragments whose trait clusters match no existing registry entry above threshold.
2. **Candidate-class proposal:** the LLM drafts a candidate entry (label, culture/era coords, class notes, distinguishing traits, nearest existing classes + distances) — provenance `inferred`, confidence by cluster size and recurrence across independent sources.
3. **Human gate:** candidates queue for approval exactly like interpreted captures; approved classes get a registry version bump and enter the analogue-mapping workflow (what existing classes does it neighbor/replace?).
4. **Registry version control:** the registry is a versioned data file; additions/edits are diffable like everything else (canon §6).

This is the "Archetype file that learns" — it never self-publishes; it drafts and queues. Expected yield: internet-slang cultures (CN especially) generate new classes fastest; the folk registries (Xiaohongshu tags, dere wikis, fandom wikis) are the natural pre-approval signal sources.

## 6. Import Order (build recommendation)

1. Import backbone: Wikipedia stock characters + TVTropes top-tier classes (US + neutral).
2. JP dere taxonomy + adjacent classes (densest, best-maintained).
3. CN internet-slang set (the Green Tea Bitch 绿茶婊 family + Xiaohongshu tag survey) — newest, fastest-moving, most in need of era pinning.
4. IN Bollywood binary set + BR novela set (era-sliced).
5. Turn on self-learning proposals once 1–3 are in (gives the matcher a real baseline to be unmatched against).
