Memory / Knowledge Separation

Inheritance permissions

MemoryWhat this character personally experienced and can remember.
KnowledgeWhat this character actually knows, rather than what a source persona knows.
BehaviorPatterns from source characters may influence reactions without importing their history.
RelationshipRelationships are independent reference objects with their own evidence and interaction patterns.
Three Visible Systems

The user-facing architecture

1. CharacterCharacters, transformations, evidence, relationships and behavioral references.

2. WorldLocations, entities, rules, events, hazards, NPCs and world-side relationships.

3. WritingScene construction, prose, dialogue, style and final fiction generation.
Downstream Computation

What the user does not need to manually author

  • Behavior extraction
  • Interaction patterns
  • State activation
  • Relevant-memory retrieval
  • World-event consequences
  • Character reactions
  • Scene simulation
  • Context assembly for the writing model
