Data Library

Import JSON packets containing episode anchors, transcript chunks, behavior schemas, character profiles, transformation states, or writing-style examples. Imported packets can be enabled/disabled for the next run. One JSON file can contain one entry, an entries array, or a dataset object.
Supported JSON packet shapes

  "kind": "transformation_state",
  "id": "rainee_state_03",
  "characterId": "Rainee_PostDump",
  "name": "Rainee · State 3 · Custom",
  "stage": "custom transformation state",
  "voice": "...",
  "cognition": "...",
  "priorities": ["..."],
  "retainedTraits": ["..."],
  "newConstraints": ["..."],
  "escalationRules": ["..."]
}
