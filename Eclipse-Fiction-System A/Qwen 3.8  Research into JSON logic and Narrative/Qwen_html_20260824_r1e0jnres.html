The architecture is divided into five core subsystems:

  • 3 The Spatial & Ontological Environment (world): Defines the physical rules, cultural layers, and object permanence of the simulation space.
  • 4 The Social Graph (relationships): Maps the interpersonal dynamics, power structures, and interaction protocols between agents.
  • 5 The Event-Driven Plot Scheduler (emergent_events, scene_comedy_mechanics): A probabilistic state-machine that dictates how the narrative progresses, handling triggers, beat sequences, and escalation chains.

Part 3: Detailed Module Breakdown (The "API")

For the research team, here is the technical translation of the JSON keys into narrative modeling concepts:

1. behavior_compiler (The Reference Firewall & Meta-Engine)

  • Narrative Concept: Source-Code Isolation & Negative Constraint Solving.
  • Function: Prevents the LLM from collapsing into "reference mimicry". It uses a lexical_denylist and rewrite_protocol to force the LLM to generate native behavior based on abstract tags rather than copyrighted archetypes.
  • Research Value: Demonstrates how to use structured JSON to enforce stylistic originality and prevent LLM mode-collapse.

2. characters (Agent Architecture)

Each character is modeled as a complex autonomous agent.

  • psych_engine & utility_drives: Implements Utility AI. Agents weigh internal drives (e.g., Rainee's commerce: 1.0 vs dignity: 0.9) to determine their next action.
  • identity_fsm: A Finite State Machine. Rainee has distinct states. The JSON defines the exact probabilistic triggers that cause state transitions (e.g., extreme stress -> 70% chance to drop to Layer 4).
  • voice_grammar & laughter_mechanics: Lexical & Procedural Generation Rules. Defines the exact syntax, filler words, and multi-stage physical reactions to ensure procedural consistency.

3. world (Spatial & Ontological Environment)

  • Narrative Concept: Multi-Layered Ontological Mapping.
  • Function: The world is not a single setting, but four overlapping layers. The fusion_doctrine dictates that comedy arises from the collision of these layers (e.g., a 1930s Art Deco ballroom used as a spirit-market for kiln-fired diapers).

4. relationships (The Social Graph)

  • Narrative Concept: Directed Interaction Matrices.
  • Function: Defines the exact nature of edges between nodes (agents). It explicitly locks certain dynamics (e.g., sisters, not romantic) while defining the "game" they play with others (e.g., taboo-play teasing).

5. emergent_events & scene_comedy_mechanics (Plot Scheduler)

  • Narrative Concept: Probabilistic Event Graphs & Anti-Resolution Mechanics.
  • Function: Instead of a linear plot, the story is a series of events with assigned probabilities. escalation_chains explicitly forbids standard narrative resolution. If a problem occurs, it must be upgraded, ensuring the narrative momentum never stalls.

If your research team is studying LLM-driven Narrative Modeling, this JSON highlights three major architectural innovations:

  2. Probabilistic Anti-Resolution: Traditional narrative models aim for climax and resolution. This JSON models comedic escalation. The escalation chains and banned modes mathematically force the narrative to reject closure, creating an infinite, looping state of comedic tension.
